    What lampfish reads and changes

    Each service, one by oneNothing leaves the PC except the connections above, and every change can be undone
    HomeChanges nothing by itself
    Reads
    The time, the weather and what This PC shows
    Changes
    Nothing: its shortcuts use the other services
    To undo
    Nothing to undo
    ThemesApplies a saved setup when asked
    Reads
    The current wallpaper, effects, cursors and sounds, to save them
    Changes
    What a theme holds, when you apply it or when its trigger starts it, and the apps it opens
    To undo
    Undo in the toast after applying
    WallpaperA window behind the desktop icons
    Reads
    The files of the wallpapers folder
    Changes
    Nothing in Windows: the Windows wallpaper stays as it is
    To undo
    Quit lampfish to see the Windows wallpaper again
    CreateMakes wallpapers in its own folder
    Reads
    The images and logo you add
    Changes
    A new folder in the wallpapers of lampfish
    To undo
    Remove the wallpaper, with Undo
    IconsFolder icons and a right-click menu
    Reads
    The icons of Windows, read in place and never copied
    Changes
    The desktop.ini file of the folders you choose, and the right-click menu if it is on
    To undo
    Back to original, Reset everything, or uninstalling lampfish
    MouseCursors and pointer settings
    Reads
    The cursor settings of Windows
    Changes
    The cursors, the cursor size and the pointer settings of Windows
    To undo
    Back to original, or uninstalling lampfish for the cursors
    SoundsPlays a sound on Windows events
    Reads
    Windows events: lock, sleep, power, USB devices
    Changes
    Nothing in Windows: it only plays its own sounds
    To undo
    Nothing to undo
    DisplayScreen, brightness and power
    Reads
    The screens, their brightness and the power settings
    Changes
    Warm screen through the accessibility color filter, which goes away with lampfish, brightness, the main screen, dark mode, sleep delays and energy saver
    To undo
    Undo in the toast after each change
    AudioChooses the default devices when asked
    Reads
    The audio devices, their format, volume and level
    Changes
    The default output and input, the volume and mute of each device and of the microphone, and a keyboard shortcut when it is on
    To undo
    Undo for 8 seconds, or the same control
    TaskbarLook and behavior of the taskbar
    Reads
    The taskbar settings of Windows for this user
    Changes
    The same settings that Windows has in its Taskbar page, and its automatic hiding
    To undo
    Undo for 8 seconds after a change, or Put the taskbar back as it was
    ArrangeMoves the desktop icons
    Reads
    The position and size of the desktop icons
    Changes
    Where the icons are, their size, and auto arrange and align to grid
    To undo
    Undo, Back to original or a saved arrangement
    NotesWrites Markdown files in one folder
    Reads
    The notes of its folder, and the list of vaults Obsidian keeps, to offer them
    Changes
    Only the .md files of its folder, saved as you type
    To undo
    Remove, with Undo for 8 seconds, then the Recycle Bin of Windows
    ShelfKeeps copies of files and captures
    Reads
    The files you drop or add, and the screen when you take a capture
    Changes
    Nothing outside its folder: files are copied, never moved, and a capture goes to the clipboard
    To undo
    Remove, with Undo for 8 seconds, then the Recycle Bin of Windows
    ConvertImages, PDF and text, on this PC
    Reads
    Only the files you pick or drop on it
    Changes
    Nothing in Windows: the results are new files in the Shelf, and the originals are never touched
    To undo
    Remove the results from the Shelf
    AssistantA button and a small window
    Reads
    What its tabs show
    Changes
    Only what you touch in it
    To undo
    Each setting can be turned back
    PluginsWhat is added to lampfish
    Reads
    What each plugin says it reads
    Changes
    Nothing by itself
    To undo
    Turn the plugin off
    HealthTurns startup programs on or off when asked
    Reads
    Antivirus, firewall, Windows Update history, BitLocker, Secure Boot, account control, startup programs and load
    Changes
    Whether a program of this user starts with Windows, as the startup apps of Windows do, and the privacy switches of Windows for this user
    To undo
    Undo for 8 seconds, or the same switch
    TasksCloses programs only when asked
    Reads
    The running programs, their files, startup entries and connections
    Changes
    Closes a program when you click Close or Free up memory, after a warning
    To undo
    An app can be opened again
    StorageChanges two File Explorer options when asked
    Reads
    The names and sizes of the files in the analyzed folder
    Changes
    Whether File Explorer shows file extensions and hidden files
    To undo
    Undo for 8 seconds, or the same switch
    DuplicatesSends copies to the Recycle Bin only when asked
    Reads
    The names, sizes and content of the files of 1 MB or more in the chosen folder
    Changes
    Moves extra copies to the Recycle Bin after a confirming click, never the last copy
    To undo
    Undo for 8 seconds, then the Recycle Bin of Windows
    HardwareReads, changes nothing
    Reads
    The parts of the PC and their load, without a driver
    Changes
    Nothing
    To undo
    Nothing to undo
    NetworkReads, tests only when asked
    Reads
    The network adapter, the Wi-Fi and the addresses
    Changes
    Nothing: the speed test reaches Cloudflare or OVH only when you run it
    To undo
    Nothing to undo
    HelpReads and changes nothing by itself
    Reads
    Nothing: it shows what the other services already read
    Changes
    Nothing: its buttons use the other services
    To undo
    Nothing to undo
    SettingsStart with Windows and the window
    Reads
    Its own settings file
    Changes
    Start with Windows when it is on, the right-click menu of Icons, and the shortcuts of the assistant when it is on
    To undo
    Turn the option off, or uninstall lampfish
